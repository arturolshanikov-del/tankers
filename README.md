# Hormuz Strait Tanker Counter

Подсчёт танкеров (ярких точек на тёмном фоне) в Ормузском проливе по
космоснимку, наложенному на картографическую основу.

## Алгоритм

1. Декодирование PNG → буфер RGBA с помощью lodepng
2. Перевод RGBA → grayscale по формуле яркости Rec.601:
   `Y = 0.299 R + 0.587 G + 0.114 B`
3. Сглаживание ядром Гаусса 5×5 для подавления шумов и одиночных
   ярких пикселей фона
4. Адаптивный порог `μ + k·σ` (по умолчанию `k = 3.5`) — отсекает всё,
   что не является «выбросом яркости»
5. Маскирование пикселей вне полигона пролива (14 вершин, обходим тёмную
   водную область по часовой стрелке)
6. Поиск связных компонент итеративным BFS по 8-связности (без
   рекурсии — устойчиво к большим компонентам)
7. Отбраковка компонент по размеру: `[min_size, max_size]`
   (по умолчанию `[4, 800]` пикселей). Это убирает спекл-шум снизу
   и крупные осветлённые области сверху

## Зависимости

- C99-совместимый компилятор (gcc / clang)
- libm

## Сборка

```bash
make
```

## Запуск

```bash
./tankers <путь к png>          # путь к изображению
./tankers tankers.png 4 800 3.5 # min_size, max_size, k_sigma
```

Если аргументы опущены, используется `tankers.png` в текущей директории.

## Вывод

- В stdout — число найденных танкеров (`Tankers found: N`)
- На диск:
  - `01_grayscale.png` — изображение после grayscale + Гаусса
  - `02_mask.png` — итоговая бинарная маска (после порога, полигона
    и фильтра по размеру)
  - `03_detections.png` — оригинал с найденными танкерами,
    закрашенными красным

## Структура репозитория

```
.
├── Makefile          сборка через make
├── README.md         этот файл
├── main.c            алгоритм подсчёта
├── lodepng.c         сторонняя библиотека для PNG (Lode Vandevenne)
├── lodepng.h
└── tankers.png       исходный космоснимок (положить рядом)
```

## Параметры под другую картинку

Полигон пролива в `main.c` подобран под апскейленную картинку (ширина
≈ 4720 px). Если используете другое изображение — отредактируйте
константный массив `poly[]` в `main()`. Координаты в пикселях,
формат `{x, y}`.
